# dev Workspace

This context defines the projects, repository activity, and reusable agent skills shown in the dev workspace.

## Skills

**Skill**:
An instruction set that helps an AI agent perform a kind of task.
_Avoid_: Prompt, agent

**Skill entry**:
A saved library record for a skill, including its description, tags, category, source, and offline copy.
_Avoid_: Skill card, installation

**Skill candidate**:
A skill source found in a repository or search result that has not yet been added to the library.
_Avoid_: Search hit

**Offline copy**:
The local files saved for an imported skill so its preview remains available without its source.
_Avoid_: Cache (when referring to the user-visible saved skill)
